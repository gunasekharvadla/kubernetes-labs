# Kubernetes Labs

> **Production-oriented Kubernetes hands-on labs for DevOps, SRE, and Kubernetes Administration**

A structured collection of hands-on Kubernetes labs designed to build and demonstrate **real-world Kubernetes administration, operations, troubleshooting, and production engineering skills**.

The repository covers Kubernetes from core workload management through **networking, storage, security, scheduling, observability, cluster administration, troubleshooting, and cloud-native Kubernetes on AWS**.

## 🚀 Areas Covered

* **Kubernetes Fundamentals** — Architecture, Pods, Namespaces, Labels & Selectors
* **Workload Management** — Deployments, ReplicaSets, StatefulSets, DaemonSets, Jobs & CronJobs
* **Configuration Management** — ConfigMaps, Secrets & Environment Variables
* **Networking** — Services, DNS, Ingress, EndpointSlices, NetworkPolicies & CNI
* **Storage** — PV, PVC, StorageClasses, CSI & Stateful Workloads
* **Resource Management** — Requests, Limits, QoS, HPA & Scheduling
* **Scheduling** — Node Affinity, Taints, Tolerations & Pod Placement
* **Security** — RBAC, ServiceAccounts, SecurityContext & NetworkPolicies
* **Cluster Administration** — Nodes, Kubelet, Control Plane, etcd, Upgrades & Maintenance
* **Troubleshooting** — Pod, Deployment, Service, DNS, Networking, Storage & Node failures
* **Observability** — Metrics, Logging, Monitoring & Kubernetes Health
* **Production Operations** — High Availability, Backup/Restore, Disaster Recovery & Capacity Management
* **Cloud Kubernetes** — Amazon EKS, AWS Networking, IAM & Kubernetes Integration
* **DevOps Ecosystem** — Helm, GitOps and CI/CD integration

## 🎯 Repository Objective

The goal of this repository is to demonstrate **practical Kubernetes administration and troubleshooting capability** through reproducible hands-on labs, operational scenarios, and documented execution evidence.

Each lab includes:

* 📋 Scenario & objective
* 🧩 Kubernetes concepts
* 📄 Production-style manifests
* 💻 Commands and operational procedures
* 📊 Actual execution output
* 🔧 Troubleshooting scenarios
* 🛠️ Diagnosis and remediation
* 🎯 Interview-focused questions
* 📝 Key operational takeaways

## 🧪 Hands-on Environment

The labs are primarily designed to be reproducible using **Kind-based Kubernetes clusters**, with advanced cluster-administration scenarios extending to **Linux/Kubeadm environments and AWS EKS**.

## 📌 Philosophy

> **Learn → Deploy → Break → Troubleshoot → Fix → Document**

The focus is not only on creating Kubernetes resources, but also on understanding **how workloads behave, how failures are diagnosed, and how Kubernetes is operated in production environments**.
