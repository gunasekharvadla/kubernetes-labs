# Kubernetes Labs

**Production-oriented, hands-on Kubernetes labs for DevOps, SRE, and Kubernetes Administration.**

A structured collection of labs built to demonstrate real-world Kubernetes skills — administration, operations, troubleshooting, and production engineering — with reproducible evidence, not just theory.

---

## 📖 Philosophy

> **Learn → Deploy → Break → Troubleshoot → Fix → Document**

The goal isn't just to spin up Kubernetes resources — it's to understand how workloads behave under stress, how failures get diagnosed, and how clusters are actually operated in production.

---

## 🚀 Areas Covered

| Area | Topics |
|---|---|
| **Fundamentals** | Architecture, Pods, Namespaces, Labels & Selectors |
| **Workload Management** | Deployments, ReplicaSets, StatefulSets, DaemonSets, Jobs & CronJobs |
| **Configuration** | ConfigMaps, Secrets, Environment Variables |
| **Networking** | Services, DNS, Ingress, EndpointSlices, NetworkPolicies, CNI |
| **Storage** | PV, PVC, StorageClasses, CSI, Stateful Workloads |
| **Resource Management** | Requests, Limits, QoS, HPA, Scheduling |
| **Scheduling** | Node Affinity, Taints, Tolerations, Pod Placement |
| **Security** | RBAC, ServiceAccounts, SecurityContext, NetworkPolicies |
| **Cluster Administration** | Nodes, Kubelet, Control Plane, etcd, Upgrades & Maintenance |
| **Troubleshooting** | Pod, Deployment, Service, DNS, Networking, Storage & Node failures |
| **Observability** | Metrics, Logging, Monitoring, Cluster Health |
| **Production Operations** | High Availability, Backup/Restore, Disaster Recovery, Capacity Management |
| **Cloud Kubernetes** | Amazon EKS, AWS Networking, IAM Integration |
| **DevOps Ecosystem** | Helm, GitOps, CI/CD Integration |

---

## 🎯 Objective

Demonstrate practical Kubernetes administration and troubleshooting capability through reproducible hands-on labs, operational scenarios, and documented execution evidence.

Every lab follows the same format:

- 📋 Scenario & objective
- 🧩 Kubernetes concepts
- 📄 Production-style manifests
- 💻 Commands & operational procedures
- 📊 Actual execution output
- 🔧 Troubleshooting scenarios
- 🛠️ Diagnosis & remediation
- 🎯 Interview-focused questions
- 📝 Key operational takeaways

---

## 🏗️ Lab Progression

```
Fundamentals → Workload Management → Networking → Storage
      → Scheduling & Resources → Security → Troubleshooting
      → Cluster Administration → Observability
      → Production Operations → AWS EKS → Advanced Kubernetes
```

---

## 🧪 Hands-on Environment

Labs are primarily built on **Kind**-based clusters for easy reproducibility, with advanced cluster-administration scenarios extending to **Linux/Kubeadm** environments and **AWS EKS**.
